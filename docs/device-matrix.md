## Skenario pengujian

1. Buka halaman melalui HTTPS, lalu izinkan kamera depan.
2. Uji wajah dalam pencahayaan terang, redup, dan bergerak.
3. Ganti kedua filter dan pastikan aksesori menempel pada landmark.
4. Ambil foto, periksa hasil unduhan, dan buka kembali galeri.
5. Muat ulang halaman untuk memastikan filter terakhir tetap dipilih.
6. Tolak izin kamera dan pastikan pesan kesalahan muncul.
7. Putar perangkat antara orientasi potret dan lanskap.
